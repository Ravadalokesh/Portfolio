# Portfolio Website

## Folder Structure

```
portfolio/
├── index.html          # Main portfolio page
├── css/
│   └── style.css      # Stylesheet
├── js/
│   └── script.js      # JavaScript functionality
├── images/
│   └── profile.jpg    # Profile picture (add your image here)
└── docs/
    └── resume.pdf     # Resume file
```

## To Complete Your Portfolio

Please fill in the following information from your resume:

1. **Education Section** (in index.html):
   - [University Name]
   - Expected Graduation: [Year]
   - Current Year: [Sophomore/Junior/Senior]
   - [High School Name]
   - Graduated: [Year]

2. **Contact Information** (in index.html):
   - Email: your.email@example.com
   - LinkedIn: linkedin.com/in/yourprofile
   - GitHub: github.com/yourusername

3. **Profile Picture**:
   - Add your profile picture as `images/profile.jpg`

4. **Projects**:
   - Update project descriptions with your actual projects
   - Add links to your GitHub repositories

5. **Skills**:
   - Update skills list based on your resume

## How to View

Simply open `index.html` in your web browser to view the portfolio.
